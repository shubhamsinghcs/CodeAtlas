# CodeAtlas Screenshots

This directory contains screenshots for the README and documentation.

## Required Screenshots

To maintain a professional appearance, ensure all screenshots follow these guidelines:
- Capture at **1920x1080** resolution.
- Use a **dark theme** browser profile.
- Do not include the browser UI (tabs, address bar). Only capture the viewport.
- If necessary, add a subtle 1px border (`#2e323b`) around the image before uploading to GitHub.

### 1. `dashboard-overview.png`
- Location: `http://localhost:3000/`
- What to show: The repository title, quick stats (Files, Dependencies, Language), and the Quick Actions.
- Goal: Immediate understanding of what the tool analyzed.

### 2. `dependency-graph.png`
- Location: `http://localhost:3000/graph`
- What to show: A zoomed-in view of a complex, interconnected cluster of nodes.
- Goal: Show the scale and visual mapping capability.

### 3. `impact-analysis.png`
- Location: `http://localhost:3000/graph` (with Impact Panel open)
- What to show: The impact side-panel open on the right, with a red/orange "High Risk" badge, while the background graph highlights the transitive blast radius in blue.
- Goal: Demonstrate the "blast radius" feature.

### 4. `ai-architecture.png`
- Location: `http://localhost:3000/files`
- What to show: The AI-generated architectural summary or implementation plan for a specific file.
- Goal: Highlight the LLM integration.
